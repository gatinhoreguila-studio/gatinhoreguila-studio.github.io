# Working rules

This repository is public (GitHub Pages). Everything here can be read by anyone: files, commit messages, pull requests and comments.

- Never write passwords, keys, tokens, personal emails, addresses, money figures or internal work notes in files, commits, PRs or comments.
- Keep commit messages and PR descriptions to one or two short lines about what changed on the site.
- Only files the site actually uses. No originals, drafts, unused files, work documents or build outputs.
- Photos and videos: web-sized only (photos 720px wide or less, videos a few MB), with location and camera data stripped.
- No photos of customers or recognizable faces. Code comments stay short and neutral.
